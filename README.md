# Hyrox Training Tracker

A single-file, installable PWA for tracking Hyrox race training on a rotating shift schedule. Training is organized as a flexible queue tied to shift-cycle position rather than fixed calendar dates.

Open the live app: enable GitHub Pages on this repo (Settings → Pages → source: `main` branch, `/` root), then visit the published URL. Add it to your home screen for an app-like, offline-capable experience.

All data is stored locally in your browser (`localStorage`) — nothing is sent to any server. Use the backup/restore feature on the History tab to move your data between devices or back it up.
